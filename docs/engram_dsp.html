DSP Reference

The signal path, algorithms, and settings behind ENGRAM FM, at the detail the manual omits. Formulas are in plain DSP terms.

v0.44

Scope & Model

what runs, and at what rate

Engram is a single-sideband (SSB) quadrature modulation engine. The input (the modulator) is multiplied against an internal wavetable oscillator (the carrier) through a 90°-phase architecture, producing frequency shifting, ring modulation, and amplitude modulation on one path, with a second algorithm swapping the shift for FM-style phase modulation. This follows the Bode frequency-shifter / ring-modulator convention: carrier = internal oscillator, modulator = input.

This document describes what the DSP does, stage by stage. For musical intent and sound design, see the Manual & Technical Reference.

Sample-rate model

The core runs at 4× oversampling. Everything time- or frequency-dependent inside the core (delay-line lengths, glide coefficients, engine filter cutoffs, diffusion delays, feedback-delay slew) is computed against the oversampled rate (host rate × 4), so behaviour holds across host sample rates.

Three stages are deliberate base-rate exceptions:

Base-rate stageWhy it is not oversampled
Envelope followerA control-rate detector that sits below the oversampling boundary; running it at 4× would give the wrong time constants.
LFO bankA control-rate generator; its time constants are defined at the host rate.
Output filterRuns at the base rate, now ahead of the output clip (moved pre-clip in v0.9.43.14 so the clip stays the last shaping stage and holds the ceiling; a post-clip filter phase-shifts the clamped waveform into peaks above 0 dBFS). Frequency-prewarped, so the resonant peak lands correctly at any rate and the base-rate response is accurate to ~0.01 dB — order-independent, verified by measurement. The clip now follows it, but the clip was always the base-rate aliasing source and an LP ahead of it only reduces its HF input.

Latency

Reported latency is the oversampler's latency only (~4 samples at the host rate), which keeps the zero-delay dry path aligned with the wet path. The wet path additionally carries the Hilbert network's bulk delay (impulse onset ~8 samples) plus a long dispersive ringing tail. That tail is dispersion, and is deliberately not delay-compensated: reporting the wet onset instead would buy under 0.1 ms and pull the dry path early.

Precision   Carrier phase accumulation and the sideband matrix run in double precision; the audio buffers and filters run in single precision. Carrier frequency, phase increment, and the Hilbert allpass states are kept in double because phase error accumulates over time.

Signal Chain

stage order

The main signal path runs left to right. The input path (magenta) enters the oversampled core (teal) along the main row, and the carrier feeds down from the row above. The feedback loop (amber) runs against that flow: it taps off after the core and returns right-to-left along the bottom, re-entering ahead of the Hilbert network (the arrowhead marks the reversed direction). Everything between the UPSAMPLE and DOWNSAMPLE boxes runs at 4× the host rate. The diamonds are BPMN gateways: + (parallel) marks the carrier join, where both branches always proceed; O (inclusive) marks the feedback re-entry and tap, where the loop may or may not be in circuit (feedback amount, or bypass); × (exclusive) marks the EXP / ADD split and re-join, where exactly one algorithm is active at a time. The carrier multiply itself lives inside the cos/sin ROTATE and × CARRIER boxes.

Reading the flow: the input is upsampled 4×, then per channel takes input gain and the input filter and reaches the sum node, where the filtered, scaled feedback is added. The Hilbert network splits that into an in-phase / quadrature pair, and the shift / PM matrix combines it with the carrier (a band-limited, mip-selected wavetable, filtered first and read as a cos/sin pair). The result is the wet signal, which branches two ways:

Into the loop: a tanh soft-clip keeps the loop bounded, then the delay line, feedback filter, diffusion, cross-feed, and amount return it to the sum node ahead of the Hilbert stage. Out of the core: the wet is decimated 4× back to the host rate, where output gain drives it through the output filter into the selectable clip stage, then the dry/wet blend against the saved dry copy.

Loop topology   Feedback returns before the Hilbert network, so the Hilbert allpass chain and the input filters sit inside the feedback loop. A flush must therefore clear them along with the delay line and diffusion buffers.

Oversampling

4x, polyphase IIR

The whole core runs at 4×, built from two cascaded 2× half-band stages. The nonlinear stages (the feedback drive clip, the shift/PM multiply, and the carrier itself) generate content above the base Nyquist; oversampling gives them headroom before decimation folds anything audible back down.

PropertyValue
Factor4× (two half-band stages of 2×)
Filter typePolyphase IIR half-band; low-latency band-limiting
Channels2 (stereo)
Shared structure   The oversampler's half-band filters and the Hilbert network are both polyphase-IIR allpass structures, designed by the same method (Laurent de Soras' HIIR technique). The oversampler applies it as a band-limiting decimator; the Hilbert chain applies it as a 90° phase splitter.

Filters

state-variable, shared design

Every filter in Engram (input, carrier, feedback, and output, each with a highpass and a lowpass) is a topology-preserving (zero-delay-feedback) state-variable filter. Cutoff is frequency-prewarped, so the resonant peak lands at the requested frequency at any sample rate. The input, carrier, and feedback filters run at 4×; the output filter runs at the base rate.

PropertyValue
Cutoff range2 Hz – 20 kHz
Resonance (Q) range0.1 – 18
Default Q0.7071 (Butterworth, maximally flat)
Slopes12 dB/oct (one stage) or 24 dB/oct (two cascaded stages)
Display ceilingQ = 18 shows as ~25 dB of resonant peak

24 dB/oct cascade

The 24 dB/oct slope cascades two filter stages. To keep the composite response maximally flat at the default Q, the two stages take the 4-pole Butterworth section Q values rather than both using the dialled resonance:

// 24 dB/oct: stage 1 Q = 0.5412 // = 1 / (2·cos(π/8)), fixed, independent of the dial stage 2 Q = clamp(dialQ × 1.8478, 0.1, 18) // = 2·cos(π/8); dialQ 0.7071 -> 1.3066 // 12 dB/oct: stage Q = dialQ

At the default dial Q of 0.7071 the two stages become 0.5412 and 1.3066, the 4-pole Butterworth pair (maximally flat 24 dB/oct). Raising the dial pushes stage 2 more resonant while stage 1 stays fixed.

No cutoff smoothing   Cutoff and Q moves are applied raw, without a smoothing ramp. A resonant filter swept faster than its own ring time will "zap", which is expected filter behaviour. For a slew, shape the modulating LFO. When the slope is switched back to 12 dB, the idle second stage is cleared so stale energy cannot blip on re-engage.

Carrier Oscillator

wavetable, mips, glide, quadrature

The carrier is a single-cycle wavetable oscillator. In shift mode it supplies a quadrature (sine/cosine) pair; in PM mode only its real leg is used. Its waveform is either drawn in the node editor (custom table) or extracted from an audio-file crop (external table).

PropertyValue
Table size2048 samples, linear interpolation
Default frequency130.81 Hz (C3)
Frequency range0 – 8000 Hz
Anti-aliasing4 band-limited mip tables (FFT-baked)

Mip anti-aliasing

The table is baked into 4 band-limited copies by FFT (forward transform, zero the bins above the cutoff, inverse). Each mip keeps a fixed harmonic count; the cutoffs are spaced ×4 to match the 4× oversampling, so the selected mip always holds every audible harmonic and none that alias, at any host rate.

// harmonic-count cutoff per mip (brightest -> dullest) mip 0: 1024 harmonics mip 1: 256 harmonics mip 2: 64 harmonics mip 3: 16 harmonics // selection, per sample, from carrier freq and the oversampled rate safeHarmonics = floor( (rate × 4) / (2 · carrierHz) ) pick the brightest mip whose cutoff ≤ safeHarmonics

All 4 mips are normalised by the brightest mip's peak, so there is no amplitude jump at a mip crossover.

Quadrature pair

The imaginary leg is the same table read a quarter cycle ahead:

real leg = table( phase ) imag leg = table( phase + 0.25 ) // +90 deg, shift mode only

Glide

Carrier frequency changes are smoothed by a one-pole toward the target, per oversampled sample. The coefficient is set from the glide time against the oversampled rate; under 0.5 ms it snaps (coefficient = 1).

coeff = 1 − e^( −1 / (rate × 4 · t) ) // t = glide time in seconds freq += (targetFreq − freq) · coeff // per oversampled sample

Tempo sync (carrier)

With sync on, the carrier frequency is stepped through beat divisions rather than set in Hz. There are 11 divisions, each an exact power-of-two multiple of the tempo reference, scaled by a note-duration type (straight / dotted / triplet).

Divisions (straight)Multipliers
8 bar … 1/128 0.03125 … 32.0 (×2 steps)
Duration typestraight 1.0 · dotted 1.5 · triplet 0.6667

Hilbert Network

polyphase IIR 90-deg splitter

The analytic (90°-phase) pair of the input is formed by a polyphase IIR allpass network: two parallel branches whose outputs differ by ~90° across the band. It replaces an FIR Hilbert transform with a few allpass multiplies and near-flat magnitude.

Section form

Each of the 4 stages per branch is a second-order allpass in the π/2 phaser form (a − z⁻²) / (1 − a·z⁻²), run as:

y[n] = a · ( x[n] + y[n−2] ) − x[n−2] // per channel: 4 stages on branch A, 4 on branch B A = allpass chain with coefficients a[0..3] B = allpass chain with coefficients b[0..3] A = one-sample delay of A // aligns the A/B pair to 90 deg

Branch A drives the real leg of the analytic signal, branch B the imaginary leg. The extra one-sample delay on A brings the two branches into a 90° relationship.

Coefficients

The 8 coefficients are computed when the engine prepares, from the oversampled rate, with a transition band set to keep phase accuracy down to 20 Hz:

transition band = 20 Hz / (oversampled Nyquist) 8 coefficients -> 4 for branch A, 4 for branch B

At a 44.1 kHz host rate (176.4 kHz oversampled) the design produces:

branch A: 0.6924 0.9361 0.9882 0.9987 branch B: 0.4022 0.8562 0.9723 0.9953
Rate-dependent   These coefficients are recomputed for the actual oversampled rate whenever the engine prepares, so phase accuracy holds across host sample rates. The values above are the design at 44.1 kHz, shown for reference.
Inside the loop   The Hilbert states sit inside the feedback loop and ring for hundreds of samples (a dispersive tail). A flush must zero all allpass states and the A-branch delay, or the ring re-seeds the just-emptied delay line. The tail is also why the wet path's true onset (~8 samples) is longer than the reported oversampler latency (~4).
Stereo drift is intrinsic   Frequency shifting rotates phase continuously, so the two channels drift apart over time (barberpole). That is a property of the method, and allpass decorrelation does not apply.

Shift & PM Math

two algorithms

Two algorithms combine the Hilbert pair (call the two legs I and Q) with the carrier pair. Additive is the default frequency-shifter / ring-mod path; Exponential is FM-style phase modulation. The carrier is filtered before this stage in both.

Additive: frequency shift / ring mod

The Hilbert pair is multiplied by the carrier's quadrature pair to give an upper and a lower sideband; Sideband Blend equal-power crossfades between them.

USB = I · cos − Q · sin // cos, sin = carrier real / imag legs LSB = I · cos + Q · sin // equal-power blend, Sideband Blend b in [-1, +1] φ = (b + 1) / 2 · π/2 out = LSB · cos φ + USB · sin φ

At blend −1 the output is the pure lower sideband (shift down); at +1, pure upper (shift up); at 0 (default) both sidebands sum at equal power with the carrier suppressed: ring modulation.

Exponential: phase modulation

Here the filtered carrier value becomes a rotation angle applied to the analytic input. The rotator is unit-magnitude, so the output is fixed to the upper sideband and Sideband Blend has no effect. PM Depth is the timbral control.

θ = PM Depth · c // c = filtered carrier wave out = I · cos θ − Q · sin θ // unit-magnitude rotation

PM Depth ranges 0–10 (a modulation index, linear dial). Filtering the carrier first means the carrier filter shapes the modulation index while the rotator itself stays unit-magnitude.

Carrier bleed

Carrier bleed reintroduces audible carrier feedthrough, applied only while transport is playing. The two algorithms handle it differently. The additive path injects a DC offset before the Hilbert network, which re-emerges as carrier tone; the PM path mixes the raw carrier wave straight into the wet signal (a DC-offset route would degenerate to DC at low PM depth).

Additive: input += bleed // pre-Hilbert DC offset Exponential: out += bleed · carrierWave // raw carrier mixed after the matrix

Feedback Loop

drive, delay, diffusion, crossfeed

The wet signal is soft-clipped and pushed into a delay line; the delayed output is read back, filtered, diffused, cross-fed, scaled, and summed back into the input before the Hilbert stage. The whole loop runs at 4×.

Drive clip

Before entering the delay, the wet signal passes a tanh soft-clip that saturates around ±16, keeping the loop bounded:

stored = tanh( wet / 16 ) × 16 // soft ceiling at +/-16

Delay line

PropertyValue
InterpolationFractional delay, linear interpolation
Max length16 s
Time range1 ms – 16000 ms (default 15 ms)
Amount range0 – 1.5 (default 0)

Two time-change behaviours, chosen by the delay mode:

PITCH (default): the read position slews one-pole toward the target over ~5 ms; moving the read point repitches the tail (Doppler) FADE: crossfade between the old read and the new target over 30 ms (triggered once the target moves more than 1 sample)

Diffusion

A 4-stage cascade of allpass sections in the feedback path smears the discrete delay echoes. The dial is a wet blend. The allpasses always run (their buffers stay fed, so the output is coherent the instant the dial is raised), and the dial blends the diffused output against the dry feedback. The allpass coefficient is held fixed, so the smear character stays constant across the dial.

// Schroeder allpass, per stage: H(z) = ( −g + z⁻ᵀ ) / ( 1 − g · z⁻ᵀ ) g (fixed) = 0.70 delays (ms) = 4, 6, 9, 13 // converted to samples at 4x rate // wet blend, w = diffusion dial [0,1] out = dry + w · (diffused − dry) // w=0 -> exactly dry

Flush

Flush is edge-triggered (button or a routed modulation source through a near-rail trigger). On the rising edge the loop is emptied at that sample (delay line, feedback filters, diffusion buffers, the Hilbert states, and the input filters), and the oversampler reset is deferred to the next block boundary (it spans the block and cannot be reset mid-loop). All of these seed or re-seed the loop, so a partial flush lets a strongly unstable setting slowly regrow.

Output Stage

drive, clip modes, filter, mix

After decimation, each sample runs through: drive gain → the output filter (base rate) → a selectable nonlinearity (clip/limit) → dry/wet blend. The filter was moved ahead of the clip (v0.9.43.14) so the clip is the last shaping stage and its clamp reaches the blend intact — a post-clip filter phase-shifts the clamped waveform into peaks above the ceiling. Output gain is placed before the clip, so it doubles as a drive control: clean when backed off, saturated when pushed. All four modes cap at ±1.0 (0 dBFS).

g = sample × outputGain // gain in dB [-60, +24], default 0; drive x = outputFilter(g) // base-rate SVF, now pre-clip; x feeds the modes below

Clip modes

SATURATE y = tanh(x) // unity small-signal, soft everywhere HARD y = clamp(x, −1, +1) // brick-wall SOFT* y = x if |x| ≤ 0.707 // transparent below -3 dBFS y = sign(x)·(0.707 + 0.293·tanh((|x|−0.707)/0.293)) above the knee LIMITER target gain = |x| > 1 ? 1/|x| : 1 // hold |y| ≤ 1 gain follows target: ~2 ms attack, ~80 ms release y = x · gain

* SOFT is the default. It is transparent below −3 dBFS and above that knee compresses toward the 1.0 asymptote (0.707 + 0.293 = 1.0).

Filter & mix

The output filter is the same state-variable design running at the base rate; it is applied to the drive-gained signal before the clip (the x fed to the modes above), so the clip stays the last shaping stage and holds the ceiling. The final blend mutes the dry path with the input-mute gate, so a gated input bypass silences the whole input path:

out = dry · (1 − inputMute) · (1 − dryWet) + wet · dryWet
Metering   The stage publishes a post-gain pre-clip peak (the level hitting the nonlinearity, for the gain meter and dBFS readout) and a drive depth 1 − |out| / |in| (0 clean, →1 hard-clipped; for the limiter this reads as gain reduction), taken as a block maximum across both channels.

Envelope Follower

attack/release detector, base rate

The envelope follower is a per-sample attack/release peak detector with hold, threshold rescaling, an offset delay, and an output smoother. It runs at the base rate and drives the modulation matrix as its first source. Two instances (left and right) support stereo modes.

Detector

// attack / hold / release on the rectified input if in > env: env = attackCoeff ·(env − in) + in ; reset hold elif holding: count down the hold else: env = releaseCoeff·(env − in) + in // coefficient: time to fall from 100% to 1% coeff = exp( ln(0.01) / (t · rate) ) // t = attack/release time in seconds

Attack 0 (default) makes the rise instant: a true peak read, with the smoother handling any softening without changing level.

Threshold, offset, smooth

// threshold: rescale [threshold, 1] -> [0, 1], floor below to zero out = max( 0, (env − threshold) / (1 − threshold) ) // offset: a plain delay of the output (0..500 ms) // smooth: one-pole lowpass on the output coeff = 1 − exp( −1 / (t · rate) ) // t = smooth time; 0 -> pass-through smoothed += coeff · (out − smoothed)

Hold freezes the envelope at its peak for a set count of samples before release begins, so short transients sustain rather than decaying immediately. Depth is a sensitivity gain on the detector output (in dB, then clamped to 1.0) that lets a quiet source reach full scale.

The input is rectified before the detector, and the channel mode chooses what to rectify: mono Sum / Left / Right / Max, or in stereo mode Normal (each channel follows its own input) / Max (both follow the louder channel), giving two independent envelopes for stereo modulation.

LFO Bank

4x wavetable LFO + random

Four independent wavetable LFOs run at the base rate (rate 5 ms–120 s). A phasor reads the drawn shape each sample; that shape is then crossfaded against a random generator, jitter is layered on, and a one-pole smoother rounds the result. The four LFOs are the second through fifth modulation sources.

Shape, smooth, glide

The shape is a drawn single-cycle table, read at the phasor position (plus a start-phase offset). Smooth is a one-pole lowpass on the output (same form as the envelope follower's smoother) that rounds sharp corners without shifting the shape. Glide portamentos the rate itself: when the rate changes (a synced division jump, a modulated rate), the phasor frequency slews to the new value over the glide time rather than stepping, so tempo-locked LFOs bend between divisions instead of clicking. Offset adds a DC bias to the output (±2), and Stereo spreads the two channels' phase apart.

Random subsystem

The Random dial crossfades the drawn shape against a random generator. The three modes differ in how the random signal is built; the distinction is the interpolation lattice:

ModeMechanism
STEPSlew-then-hold sample & hold. On each cycle a new random target is drawn; the output smoothsteps from the previous value to it over the first glide fraction of the cycle, then holds. Glide 0 gives instant jumps (classic S&H); higher glide rounds the steps.
DRIFTPerlin gradient noise. Random slopes (±1) sit on an integer lattice; between them the output interpolates two gradient·distance terms with a smoothstep. Because the lattice stores gradients rather than levels, the curve passes through zero at every lattice point: a smooth, self-centering wander that rarely holds at an extreme.
FLOWValue noise. The lattice stores random values instead of slopes, smoothstep-interpolated between them. The output reaches those values, so unlike DRIFT it is never forced through zero: it roams the full range and lingers near the rails. Busier and less centered than DRIFT.

Both DRIFT and FLOW sum two octaves (a second, faster noise layer added to the first) and pass through an edge-shaping power curve driven by a slow noise layer, which biases the distribution toward the rails. Rand Speed scales the generator rate against the LFO rate (0.125–8×); Rand Stereo blends the right channel between a phase-lagged copy of the left and an independent noise track.

Perlin vs value noise   Same smoothstep interpolation, opposite lattice contents. Storing gradients (Perlin/DRIFT) ties the curve to zero at each node, so the motion always returns through center (gentle). Storing values (FLOW) lets each node be anywhere, so the curve holds wherever the random draw lands (wandering). Perlin: Ken Perlin, SIGGRAPH 1985.

Jitter

Jitter is a second sample-and-hold layered on before the smoother, running at its own rate (1–100 Hz) unrelated to the LFO rate. Each step draws both a new random target and a new duration of 0.5–1.5× the base interval, linearly interpolated across that span, so step heights and step lengths are both irregular. Left and right run separate accumulators (right offset half a cycle) for stereo width.

Sync & trigger

Synced, the rate steps through 13 tempo divisions (1/128 to 32 bars, each a factor-two multiple) scaled by the note-duration type; Glide (above) is what smooths the jump between divisions. LFOs also take note-on retrigger (reset the phasor on a note) and one-shot (run one cycle from the start phase, then hold).

Modulation Matrix

7 sources x 98 targets

Every routing is a cell in a 7×98 matrix. Sources are summed per target each sample; how the summed amount maps onto a target's value is decided by that target's curve, so a filter cutoff moves in octaves while a gain moves in dB. Generators are read with a one-sample delay relative to the engine (the uniform cost of the per-sample interleave).

Sources (7)
Envelope Follower, LFO 1–4, MIDI Velocity, MIDI Note

Fold & scale

// per source value s, per cell: v = unipolar ? (s + 1)/2 : s // bipolar pass-through, or remap to 0..1 right uses its own source if the cell is stereo, else mirrors left // a per-source master scale [0,4] and one global scale [0,4] fold in: amount = cellDepth · masterScale · globalScale

Disabled cells contribute exactly 0 (their depth is retained for display). The envelope follower and MIDI sources are always unipolar; the unipolar/bipolar choice applies only to LFO sources.

The rail-aware resonance curve scales the excursion to the distance from the current value to each rail, so a bipolar source reaches a rail only at full depth and never flatlines the half-cycle nearest a rail. Filter resonance clamps to [0.1, 18]. Filter stereo-spread targets add directly onto the spread amount.

Trigger & gate targets

Some targets are edges rather than continuous values: LFO retrigger, flush, and the five bypass gates. A trigger with hysteresis converts the summed modulation into rising/falling edge events, with the threshold set near the top rail so a source only fires at (or summed to) near-full depth, and the gap preventing chatter:

rise at 0.98 fall at 0.95 // re-arms only after falling back through 0.95

Bypass gates flip against the manual button state, then crossfade the effective bypass over ~2 ms (click-free); the filter or feedback path always keeps running so its state never freezes.
